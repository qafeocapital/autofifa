## Project Overview

FifaRun is a comprehensive gaming platform that enables FIFA players to:
- **Challenge opponents** across all major gaming platforms
- **Play for real money** using secure crypto payments
- **Discover fair matches** through AI-powered matchmaking
- **Build gaming communities** with social features and tournaments

### Key Objectives
- Deliver seamless, mobile-first experience
- Provide secure crypto wallet integration
- Enable AI-driven fraud detection and matchmaking
- Foster social gaming communities
- Support viral growth through affiliates and agents

## Core Features

- **🎮 Multi-Platform Gaming** - Support for PlayStation, Xbox, and PC
- **💰 Crypto Payments** - Secure wallet with USD-based platform currency
- **🤖 AI Matchmaking** - GPT-4o powered opponent matching
- **👥 Social Features** - Friends, groups, and community building
- **⚖️ Dispute Resolution** - AI-assisted dispute handling system
- **📊 Leaderboards** - Global, regional, and friends rankings
- **🏆 Achievement System** - Badges, trophies, and skill ratings

## Technical Stack

- **Frontend**: Next.js 14, React Native, TypeScript, Tailwind CSS
- **Backend**: Supabase (PostgreSQL, Auth, Storage)
- **Real-time**: Firebase (Chat, Notifications)
- **Payments**: Cpay.world non-custodial crypto gateway
- **AI Services**: GPT-4o for matchmaking and fraud detection
- **Deployment**: Vercel (web), Expo/App Center (mobile)
